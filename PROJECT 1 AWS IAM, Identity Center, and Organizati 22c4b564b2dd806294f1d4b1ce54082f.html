PROJECT 1: AWS IAM, Identity Center, and Organization Setup

Project Objective

  • Create and configure an AWS Organization with 3 member accounts
  • Set up AWS IAM Identity Center with 5 users
  • Group users by roles (Admin, DevOps, Developers)
  • Create and attach IAM policies to manage permissions

Step-by-Step Implementation

Step 1: Create a Management Account

  • Created a root/management account which serves as the primary AWS account for managing the organization.

Step 2: Sign In as Root User

  • Signed in to the AWS Management Console using the root credentials of the management account.
  • This account now acts as the AWS Organization’s root.

Step 3: Create Member Accounts

  • Intended to create 3 member accounts under the organization structure.
  • Note: AWS Free Tier does not support creating multiple linked accounts. Therefore, only the management account was used to proceed with the next configurations. All users were added to this account.

Step 5: Enable Multi-Factor Authentication (MFA)

Steps Taken:

  1. Each user is required to set up MFA during first-time login using Google Authenticator or a similar app.

Step 10: Account Allocation

Instruction:

All users must have access to all accounts, with permissions controlling their actions.

Challenge:

Due to Free Tier limitations, we could not create Dev, Staging, and Production accounts separately. All users were added to the Development (root) account instead.

Assignment Strategy:

  • Permissions were still assigned as if across multiple accounts
  • Ensured access and behavior simulation was as close to intended setup as possible
